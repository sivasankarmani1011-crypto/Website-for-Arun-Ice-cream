# 🍦 Arun Ice Cream | Local Artisan Ice Cream Shop Website

A modern, responsive, high-converting local business website built for **Arun Ice Cream** located in Kallal, Sivagangai, Tamil Nadu. Designed with mouth-watering UI/UX aesthetics, a "death scroll" storytelling experience, and a customer login/signup feature.

---

## ✨ Key Features

- **🍦 Exclusive Artisan Ice Cream Menu**: Cleaned and dedicated product catalog featuring local favorites like Vanilla, Rich Chocolate, Butterscotch Crunch, Oreo Sundaes, and Milkshakes (priced in INR ₹).
- **📜 "Death Scroll" Storytelling Experience**: An immersive vertical scroll section with reveal animations outlining the shop's 15+ year journey.
- **🔐 Customer Login/Signup Modal**: A sleek, modern authentication popup modal with smooth tab switching between Login and Sign Up.
- **🛒 Interactive Shopping Cart**: Add-to-cart counter with custom visual bounce effects and feedback states.
- **📱 Fully Responsive Design**: Mobile-friendly navigation with a hamburger menu and layout optimization for all screen sizes.
- **📍 Localized Information**: Complete store details, store hours (5:30 AM to 10:00 PM), and Google Maps direction links.

---

## 🛠️ Tech Stack

This project is built using pure, high-performance web technologies:
* **HTML5**: Semantic and accessible document structure.
* **CSS3**: Modern styling utilizing CSS Variables, Flexbox, CSS Grid, Glassmorphism effects (`backdrop-filter`), and smooth keyframe animations.
* **JavaScript (ES6+)**: Interactive DOM manipulation, Intersection Observer API for scroll-triggered animations, and event handling.
